# Dosemate
Medication scheduling and adherence tracker (CP-027) in Java.
## How to run
1. Install JDK 17 or newer
2. Download DoseMate.java
3. Run: java DoseMate.java

## Features
- Add a medicine with dose times, days and tablet count
- View today's schedule
- Mark doses as Taken or Missed
- View adherence percentage
- Low-stock alert when fewer than 3 days remain
